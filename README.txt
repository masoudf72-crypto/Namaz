نماز من — نسخه PWA

این نسخه همان برنامه فعلی است، با قابلیت نصب به‌عنوان Web App.

برای انتشار:
1. فایل‌های این پوشه را روی یک سرویس HTTPS قرار دهید.
2. فایل index.html باید در ریشه سایت باشد.
3. لینک HTTPS را با Chrome اندروید باز کنید.
4. از منوی Chrome گزینه Install app / نصب برنامه را بزنید.

GitHub Pages برای این کار مناسب است و روی دامنه github.io به‌صورت HTTPS سرو می‌شود.
